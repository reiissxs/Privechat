# PRIVE CHAT — interface mobile-first

## Publicação
Este pacote contém um `index.html` estático e `vercel.json`. Na Vercel, importe o repositório ou use Vercel Drop e envie o ZIP/pasta com os arquivos na raiz.

## O que esta versão entrega
- Nova interface mobile-first inspirada na organização das referências fornecidas, preservando a identidade vinho/dourado/creme do PRIVE CHAT.
- Navegação inferior entre Início, Chamadas, Mensagens e Perfil.
- Cards de perfis, filtros, favoritos, loja demonstrativa, telas de conversa e modal de chamada recebida (demonstração).
- Busca demonstrativa e avisos claros quando uma ação depende de backend.

## Importante antes de lançar
Esta entrega é uma **interface funcional de demonstração**, não uma plataforma de chamadas entre usuários reais. O site não tem autenticação, mensagens persistentes, saldo/checkout real, chamadas WebRTC, notificações push ou sincronização entre dispositivos. Para isso é necessário implementar backend seguro e serviços de tempo real; não se deve apresentar os controles de demonstração como funções reais nem receber pagamentos antes de ligar o checkout.

As fotos dos cards são imagens remotas de demonstração do Unsplash. Troque por fotos com licença/consentimento apropriado antes de produção.
