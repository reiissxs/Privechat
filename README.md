# PRIVE CHAT — interface refinada

Esta versão preserva a logo oficial que já existia no projeto e refina a tipografia, a navegação inferior e os ícones.

## Publicar na Vercel
Importe esta pasta em um repositório GitHub ou envie os arquivos para o repositório conectado à Vercel. O `index.html` e o `vercel.json` ficam na raiz.

## Limitações
Esta é uma interface estática/protótipo. Chamadas entre usuários, mensagens sincronizadas, notificações push, autenticação e pagamentos reais exigem backend e integrações.
